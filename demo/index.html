Interactive FAQ & Knowledge Base

How does client-side windowing work?

Interaction events (mousemove, mousedown, mouseup, scroll) are batched into non-overlapping 5-second observation frames. The client extracts 5 aggregated behavioral signals, avoiding heavy per-event network requests.

What distinguishes a rage-click from normal clicking?

Rage-clicking features rapid consecutive clicks on the identical DOM target within 300 ms, often combined with elevated cursor velocity bursts or abrupt directional reversals.

Why is the inference threshold configurable (0.85 default)?

Threshold selection controls the trade-off between false-positive user interventions (which annoy calm users) and false negatives (missing users who are quietly struggling).

Is user privacy preserved?

Yes. The telemetry captures no keystrokes, personal text, or form values. It only tracks coordinate kinematics, timestamps, and target element tags.

What happens when UI friction is detected?

The system triggers a non-intrusive contextual help intervention with a 30-second cooldown timer to prevent notification fatigue.
